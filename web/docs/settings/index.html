Settings, without guesswork

Know what to change—and what to leave alone.

Open Settings from the gear in the side panel or from your browser’s extension options. Most people only need General, Providers, and Permissions; the other tabs solve specific problems.

Everyday

General: how the agent behaves

Language and appearance are cosmetic. The controls below them change the agent loop: how it plans, when you review, how long it can work, and whether scheduled jobs can run.

Planning controls

  • Try planning is the best general choice. WebBrain attempts a structured plan before Act or Dev tools run; if planner formatting still fails after repair, that turn continues with the Ask prompt and read-only tools.
  • Strict planning cancels the run when a valid plan cannot be produced. Use it where “no plan, no action” matters more than convenience.
  • Off removes the extra full-plan call, while retaining the compact intent check and its safe read-only fallback. It can be faster and cheaper, but you lose the plan review checkpoint.

Steps and timeouts

The step limit counts tool-use steps for one message, not chat messages. Higher values allow longer workflows and more chances to recover, but they can also spend more tokens. The timeout only governs how long WebBrain waits for the model to start responding; it does not cut off a response that is already streaming.

Unlimited is not the same as reliable

Setting the step slider to ∞ removes a mechanical stop. It does not make a model less likely to loop. Keep a finite limit unless you are actively supervising a long job.

CAPTCHA solvers

General → Advanced has a dedicated block for CapSolver, 2Captcha, CapMonster Cloud, SolveCaptcha, Anti-Captcha, NopeCHA and NoneCap. Entering a key checks its enabled box; you can turn it off while keeping the key. Save persists that choice. Testing a balance does not enable solving.

Expand a provider’s Advanced section to adjust its weight. Defaults are 100 through 94 in the order above. Enable any number; compatible providers run from highest weight to lowest. Errors and timeouts can cause more than one service to charge.

hCaptcha uses NopeCHA or NoneCap. Other families have provider-specific coverage and input requirements. See the CAPTCHA guide for the full coverage table, fallback behavior, privacy and page-application limits.

Everyday

Providers: choose the brain

Only one provider is active at a time. Filter the list by Local, Cloud, or Router; search by provider, model, or field; then open a card to edit it. The safe sequence is Save → Test Connection → Set Active.

See Providers & models for local server URLs, context windows, prompt tiers, and troubleshooting.

When needed

Assistive Models: support the main agent

Choose the main conversation model in Providers. Open Settings → Assistive Models for the optional models below; configuring one does not change your active provider.

Vision and Decision models both default to Auto. In Chrome with hardware WebGPU, Auto uses Ternary Bonsai 2 2B Vision (about 1.45 GB, runs on your device) once it is downloaded, and nothing before that. The Download a local model button on the install page, Providers → WebGPU, the Vision card and Apocalypse Mode all download that same model, so one download covers chat, screenshots and decisions.

Vision

Pick what reads screenshots. An OpenAI-compatible endpoint, if you save one, reads every screenshot while the active provider keeps planning and tool calls. Without one, the active model reads screenshots itself if it can see images; if it cannot, the in-browser vision model does (Chrome only). Leave everything at its default to let the active provider handle vision. Screenshot limits and redaction are grouped here too.

The in-browser vision model has four settings:

  • Auto (default): uses Ternary Bonsai 2 2B Vision once it is downloaded and stays off until then.
  • Ternary Bonsai 2 2B Vision: about 1.45 GB. The same model also chats and answers decisions.
  • WebBrain VL 2 450M: about 810 MB, vision only. Its first download asks for your consent and checks WebGPU.
  • Off: no in-browser vision model.

Changing the setting never downloads anything; use the card’s Download button. Tasks never wait for a download, and screenshots read in the browser stay on your device. Firefox has no in-browser vision model.

Speech to text

Configure a Whisper-compatible endpoint for recordings. Leave it blank and WebBrain tries configured providers in this order: OpenAI, Groq, LM Studio, then llama.cpp.

Decision models

A decision model is a small, fast model that answers the agent’s yes-or-no and multiple-choice questions, such as “Is this task finished?”, so your chat model doesn’t have to. It never plans, clicks or types. Choose one mode:

  • Auto (default): nothing to set up. In Chrome it uses Ternary Bonsai 2 2B Vision once it is downloaded, to check whether side panel tasks and scheduled watches and tasks really finished. While WebBrain Cloud (Compass) is your chat provider, Compass’s decision model answers instead. Otherwise no decision model is used. The card shows which one is in use.
  • On: uses the provider you set up for every decision: OpenRouter, TypeSafe, a local System One server, D1, or the in-browser chat model in Chrome. All decisions are on by default. Open Choose which decisions use it to turn off individual ones (Verify completion, Verify scheduled watches, Verify scheduled task completion, Fast classifications, Fast browser actions — Experimental) and to set thresholds.
  • Off: never uses a decision model, Compass’s included. Your chat model still checks whether tasks are finished.

A mode change applies at once; On’s provider fields use Save. Test Connection sends one request with fixed example data. Reset returns to Auto and deletes saved decision keys. Cloud decision providers receive limited task and page data and may cost money; Strict Secret Mode disables decision models. Profiles that had decision outsourcing turned on before these modes keep working as On with their previous switches.

When needed

Memory: decide what persists

  • Encrypted Cloud Sync is for WebBrain Compass members. Supported provider keys, profile text, and memories are encrypted with your sync password before upload. WebBrain cannot recover that password. Chat history and OAuth sign-ins are not synced.
  • Profile auto-fill is a reusable block of personal details. It is stored in plaintext in this browser profile and sent to the active provider when enabled.
  • User memory stores durable preferences. Explicit /memory --add saves immediately. Auto-learn and learning from completed forms are optional.
Do not turn memory into a password manager

Do not store passwords, API keys, tokens, recovery codes, or other secrets in profile text or user memory.

Trust decision

Skills: extra instructions and tools

A skill can add instructions to the system prompt. A skill containing a webbrain-tools manifest can also expose HTTP or download-job tools. Imported skill text is copied into browser local storage and sent to your configured LLM as part of the system prompt.

Importing is approval

Only import a skill you trust. Its declared HTTPS tools can send their declared inputs to the declared endpoint without a new prompt for every call. Download tools still use the normal Downloads permission gate before saving a file.

Everyday safety

Permissions: where WebBrain may act

Keep Ask before consequential actions on. When you choose “Always allow” in the side panel, Settings records a specific capability for a specific site. A click grant is not automatically a typing, download, upload, JavaScript, or scheduling grant.

The same switch sits in the side panel: the ⚠ button next to the microphone in the message box opens it, with a link to the site list. While prompts are off, that button stays orange with a dot. Switching prompts off there never approves a permission card that is already waiting; answer that card yourself.

The master switch is global

Turning it off allows prompt-free actions on every site until you turn it back on. This is much broader than granting one capability to one host.
